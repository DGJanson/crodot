# Title Screen

The Title Screen is the initial landing page when Crodot starts.

It displays:
- The application name “CRODOT”
- A brief disclaimer

Shortcuts:
- **Space**: Open the function menu  
- **Esc**: Close any popup and return to Title view  
- **Ctrl+Q**: Exit the application

Function Menu:
- **n**: Create a new project  
- **o**: Open an existing project  
- **q**: Quit Crodot  

Open Project Popup:
- **[1-9]**: Select a project by its index  
- **Esc**: Cancel and return to Title view
