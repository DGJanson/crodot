# LLM Interaction Screen

This screen lets you compose and send prompts to the LLM.

Layout:
- Left panel: current LLM mode and help text  
- Right panel: editable prompt area  

Modes:
- **Main**: View the prompt  
- **Prompt**: Edit the prompt  
- **Function**: Show command menu  
- **Key Help**: Display keyboard help  

Shortcuts (Main):
- **Space**: Open the function menu  
- **f**: Toggle between Question and Coding mode  
- **F**: Enter Mock LLM mode  
- **i**: Enter prompt editing mode  
- **?**: Toggle the key help overlay  
- **y**: Yank current prompt to clipboard  

Shortcuts (Function Menu):
- **c**: Clear the prompt textarea  
- **s**: Send the prompt to the LLM  
- **x**: Reset the entire conversation (new chat)  
- **r**: Go to LLM Response screen  
- **f**: Open File Manager  
- **m**: Return to Main Menu  

Prompt Editing:
- Standard text editing keys (type, backspace, Enter)

Key Help Overlay:
- **f**: Change LLM mode  
- **i**: Edit prompt  
- **F**: Set mock mode
