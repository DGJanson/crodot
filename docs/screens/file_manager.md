# File Manager Screen

Manage the project description file and select files to include in prompts.

Layout:
- Top section: description file status  
- Bottom section: current operation (picker, edit list, overview)

Modes:
- **Overview**: Default view  
- **PickDesc**: Pick a project description file  
- **PickList**: Choose a new file to add to shortlist  
- **EditList**: Toggle and remove files in the shortlist  
- **Function**: Show navigation menu  
- **Help**: Show action help overlay  

Shortcuts (Overview):
- **d**: Set or change project description file  
- **f**: Add a file to the shortlist  
- **a**: Enter Edit List mode  
- **Space**: Open the function menu  
- **?**: Show help overlay  

Shortcuts (Help Overlay):
- **d**: Set description  
- **f**: Add file to shortlist  
- **a**: Edit active list  
- **Esc**: Close overlay  

Shortcuts (Function Menu):
- **m**: Return to Main Menu  
- **l**: Go to LLM Interaction screen  
- **r**: Go to LLM Response screen  

Shortcuts (Edit List):
- **j / k**: Move selection down/up  
- **a**: Toggle file active/inactive  
- **d**: Delete selected file  
- **Esc**: Return to Overview
